# Instrucciones

### A cada grupo se le asignará alguno de los siguientes temas:

* Burbuja
* Selección
* Inserción
* Quicksort
* Mergesort
* Heapsort
* Counting Sort
* Radix Sort

### Deberán realizar una pequeña presentación de cada tema, contemplando aspectos tales como:

* La complejidad algorítmica (peor caso, mejor caso, etc.)
* Funcionamiento del algoritmo
* Complejidad de espacio
* Estabilidad
* Adaptabilidad
