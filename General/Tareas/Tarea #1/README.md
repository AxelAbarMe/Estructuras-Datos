# Ejercicios de Python – Argumentos por Línea de Comandos

## Instrucciones

Resolver los siguientes ejercicios utilizando el lenguaje de programación Python.

Nota: Todos los ejercicios deben resolverse pasando argumentos al programa desde la línea de comandos. Más información en el siguiente [enlace](https://www.geeksforgeeks.org/python/command-line-arguments-in-python/)

## Enunciados

### 1. Saludo personalizado
Recibe un nombre y una edad, e imprime un saludo del tipo "Hola, Ana. El próximo año tendrás 21 años."

    python ej01.py Ana 20

### 2. Suma de dos números
Recibe dos números enteros y muestra su suma.

    python ej02.py 7 5

### 3. Área de un rectángulo
Recibe la base y la altura, e imprime el área y el perímetro.

    python ej03.py 4 6

### 4. Par o impar
Recibe un entero e indica si es par o impar.

    python ej04.py 9

### 5. Signo del número
Recibe un número e imprime si es positivo, negativo o cero.

    python ej05.py -3

### 6. Mayor de tres
Recibe tres números y muestra cuál es el mayor.

    python ej06.py 12 45 8

### 7. Clasificación de nota
Recibe un puntaje (0–100) y devuelve la letra correspondiente: A (90+), B (80–89), C (70–79), D (60–69), F (<60).

    python ej07.py 84

### 8. Cuenta regresiva
Recibe un número N e imprime desde N hasta 1.

    python ej08.py 10

### 9. Tabla de multiplicar
Recibe un número e imprime su tabla del 1 al 10.

    python ej09.py 7

### 10. Suma acumulada
Recibe N y calcula la suma de todos los enteros de 1 hasta N.

    python ej10.py 100

### 11. Factorial
Recibe N y calcula su factorial usando un ciclo.

    python ej11.py 5

### 12. Pares en un rango
Recibe dos números a y b e imprime todos los pares entre ellos.

    python ej12.py 3 14

### 13. Lanzamiento de dado
Recibe cuántas veces lanzar un dado, simula los lanzamientos e imprime cada resultado. Utilice la librería "random".

    python ej13.py 5

### 14. Estadística aleatoria
Recibe una cantidad N, genera N números aleatorios entre 1 y 100, e imprime el mayor y el promedio.

    python ej14.py 20

### 15. Generador de contraseñas
Recibe una longitud L y arma una contraseña aleatoria de esa longitud combinando letras y dígitos.

    python ej15.py 12

### 16. Invertir cadena
Recibe una palabra o frase y la imprime al revés.

    python ej16.py murcielago

### 17. Contar vocales
Recibe una frase (entre comillas) y cuenta cuántas vocales tiene.

    python ej17.py "Estructuras de Datos"

### 18. ¿Palíndromo?
Recibe una palabra e indica si se lee igual al derecho y al revés (ignorando mayúsculas).

    python ej18.py Reconocer

### 19. Escribir en archivo
Recibe el nombre de un archivo seguido de varias palabras, y las guarda en el archivo, una por línea.

    python ej19.py salida.txt manzana pera uva

### 20. Analizar archivo
Recibe la ruta de un archivo de texto, lo lee e imprime cuántas líneas, palabras y caracteres contiene.

    python ej20.py salida.txt
